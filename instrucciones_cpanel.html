1

Crear Base de Datos MySQL en cPanel

Ingresa a cPanel y abre el Asistente de bases de datos MySQL. Asigna un nombre a la base de datos (ej. usuario_farmacia) y crea un usuario con contraseña. Otorga Todos los Privilegios.

2

Importar database.sql en phpMyAdmin

Abre phpMyAdmin en cPanel, selecciona tu base de datos en la columna izquierda, ve a la pestaña Importar, sube el archivo database.sql y haz clic en Continuar.

3

Configurar Credenciales en api/config/database.php

Edita el archivo con el editor de cPanel colocando el nombre de tu base de datos, usuario y clave:

define('DB_HOST', 'localhost');
define('DB_NAME', 'tu_base_de_datos');
define('DB_USER', 'tu_usuario_mysql');
define('DB_PASS', 'tu_clave_segura');
4

Subir y Descomprimir farmacia_cpanel.zip

En el Administrador de Archivos de cPanel, entra a public_html/, sube el archivo ZIP y presiona Extraer.
